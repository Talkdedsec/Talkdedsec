## Desktop applications

| Application | Description | Stack |
|:--|:--|:--|
| **Talkdedsec Editor** | Windows code editor built on an open-source core with the telemetry layer removed. Own release channel, themes, docs and support flow. | TypeScript / Node |
| **Talkdedsec Visual** | Real-time screen colour engine for Windows: brightness, contrast, saturation, hue and night vision through a 5×5 colour matrix. No runtime dependencies. | Rust / Slint |
| **TLK Player** | Local music widget, seven themes, bit-perfect audio chain. | Rust / Tauri |
| **Talkdedsec Browser** | Windows browser in two builds: WebView2 and Chromium (CEF). | C# / WPF |
| **DedSec Control Center** | Windows tweak and cleanup suite with a licence model. | C# / .NET |
| **TLK Cleaner** | Disk, cache and leftover-file cleanup. | C# |
| **TLK Guard / PasteGuard** | Local clipboard and process protection. | C# |
| **Talkdedsec Recovery** | Repair toolkit for broken Windows installs. | PowerShell / C# |
