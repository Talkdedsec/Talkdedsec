## Desktop applications

| Application | Description | Stack |
|:--|:--|:--|
| **TLK Player** | Local music widget with multiple themes and a lossless audio chain | Rust / Tauri |
| **Talkdedsec Visual** | Real-time screen colour engine for Windows — brightness, contrast, saturation, hue and night vision through a 5×5 colour matrix, no runtime dependencies | Rust / Slint |
| **Talkdedsec Browser** | Windows browser, shipped in a WebView2 build and a Chromium (CEF) build | C# / WPF · CEF |
